# Organização Voluntários — SPA
Versão final da aplicação Single Page Application desenvolvida com HTML, CSS e JavaScript.

## Estrutura
- **index.html**: Entrada principal com roteador SPA.
- **/pages**: Páginas modulares carregadas dinamicamente.
- **/js/router.js**: Gerencia navegação hash-based.
- **/js/app.js**: Controla o ciclo de rotas e inicialização.
- **/script.js**: Funções de formulário, máscaras e dark mode.

## Funcionalidades
- Navegação sem recarregar (SPA)
- Validação e persistência de cadastros com localStorage
- Carrossel funcional nos projetos
- Tema escuro persistente
- Responsividade completa e acessibilidade
